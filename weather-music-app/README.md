# Weather Music App

Weather Music は、天気情報をもとに音楽を自動生成するアプリです。

まずはこの URL にアクセスすれば、すぐに使い始められます。

- https://u-22-u3x4.onrender.com/

天気の状態や都市名を入力すると、その地域の天気に合わせて曲の雰囲気や進行が自動で作られます。

## 使い方

1. ブラウザで公開 URL を開く
2. 都市名を入力する
3. 生成を実行する
4. 天気に合わせた音楽が作成される

たとえば、晴れの日は明るい雰囲気、雨の日は落ち着いた雰囲気、曇りの日は中間の雰囲気として生成されます。

### 注意事項

このアプリは、天気データの取得と Python による音楽生成を組み合わせており、処理に非常に時間がかかります。
そのため、実行開始から完了まで 50 分以上かかることがあります。

また、生成処理が重いため、現在利用しているサーバー側でタイムアウトが発生することがあります。
その場合、処理は途中で止まったり、完了まで到達しないことがあります。

このため、長時間の待機を前提に利用してください。

## ローカルで起動したい場合

### 必要環境

- Java 17
- Python 3.8 以上
- Maven または Maven Wrapper (`mvnw`)

### 起動コマンド

```bash
cd weather-music-app
./mvnw spring-boot:run
```

Windows の場合:

```bash
cd weather-music-app
mvnw.cmd spring-boot:run
```

起動後は次の URL にアクセスしてください。

```text
http://localhost:8080
```

## 生成されるもの

このアプリでは、天気情報をもとに次のような音楽要素が自動生成されます。

- 季節
- 天気の状態
- キー
- コード進行
- BPM
- MIDI / 音楽生成データ

## 注意事項

- 初回起動時には依存ライブラリの準備に時間がかかる場合があります。
- Python と Java の環境が整っている必要があります。
- 公開 URL は Render のデプロイ環境に依存するため、ローカル環境と挙動が異なる場合があります。
- 処理量が多いため、長時間の待機とタイムアウト対策が必要です。
